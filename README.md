# 🔍 Plagiarism Detection System

An AI/NLP-based plagiarism detection web application built using Python and Streamlit.

## 🚀 Features

- 🔐 User Registration & Login
- 📄 TXT, PDF and DOCX document support
- 🔍 TF-IDF similarity detection
- 🧠 Semantic similarity using Sentence Transformers
- 📊 Combined similarity score
- 🔎 Similar sentence detection
- ⚠️ Plagiarism risk assessment
- 📋 Advanced plagiarism report
- 📥 TXT, PDF and DOCX report export
- 📊 CSV history export
- 🗄️ SQLite analysis history
- 🎨 Professional Streamlit UI

## 🧠 Technologies

- Python
- Streamlit
- NLP
- TF-IDF
- Cosine Similarity
- Sentence Transformers
- Scikit-learn
- SQLite
- Plotly
- PyPDF2
- python-docx
- ReportLab
